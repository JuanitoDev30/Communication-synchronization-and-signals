Detailed Description

Cliente de carga para el servidor de tablero compartido.

Se conecta por TCP al servidor y repite una operacion un numero determinado de veces. En modo lector comprueba cada respuesta: el tablero es coherente cuando todas sus casillas contienen el mismo caracter, de modo que una respuesta con caracteres mezclados corresponde a una lectura tomada mientras un escritor estaba a mitad de su trabajo. Al terminar informa cuantas lecturas resultaron incoherentes y cuanto tiempo tomo la serie completa.
