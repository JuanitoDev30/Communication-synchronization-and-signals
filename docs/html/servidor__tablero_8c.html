Detailed Description

Servidor TCP concurrente con un recurso compartido entre lectores y escritores.

El servidor mantiene un tablero de texto en memoria. Atiende cada conexion en un hilo independiente, de modo que varios clientes operan sobre el tablero al mismo tiempo. La politica de sincronizacion se elige al arrancar:

sin - ninguna proteccion sobre el tablero mutex - exclusion mutua total: un solo cliente a la vez, lea o escriba rwlock - lectores y escritores: varias lecturas simultaneas, escritura exclusiva

Protocolo de texto, una orden por linea:

LEER -> OK <version> <contenido del tablero>
ESCRIBIR <car> -> OK <version>
SALIR -> cierra la conexion

◆ al_interrumpir()

static void al_interrumpir ( int  senal)
static

Manejador de SIGINT. Solo registra la solicitud de terminar.

Dentro de un manejador no se pueden llamar funciones que no sean seguras ante senales (printf, malloc, pthread_mutex_lock), porque la senal puede llegar en medio de ellas. El trabajo se realiza en el ciclo principal, que observa la bandera.
